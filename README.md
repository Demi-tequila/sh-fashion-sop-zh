# 上海时尚行业员工 SOP 知识库（中文版）

一份单文件、离线可用的 HTML 知识库，覆盖上海时尚行业 9 类常见公司与 8 类核心岗位的标准化作业流程。从入职清单、周常节奏、跨部门协作，到上新 / 大秀 / 危机等关键场景，再到数据复盘与红线避坑，可直接作为团队新人 onboarding 模板使用。

## 内容结构

- **认知层**：行业图谱（9 大类公司）、公司类型详解
- **执行层**：岗位 SOP 手册（8 类岗位 × 6 大场景）、技能图谱、SOP 生成器
- **方法论**：Vibe Coding 构建手记（提示词骨架 + 迭代记录 + 扩展为 Skill 的方法）

## 使用方式

直接用浏览器打开 `index.html` 即可。这是一个单文件离线应用，无外部依赖，可整页保存、内网分发、二次编辑。

页面中的「SOP 生成器」可交互：选择公司类型 + 岗位，一键生成定制版 SOP 清单。
