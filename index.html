06Vibe Coding 手记

这份知识库本身是用「vibe coding」方式产出的：用自然语言描述需求，AI 直接生成结构 + 内容 + 交互，人只做「审美与校验」。下面是复现它的提示词骨架与迭代记录。

② 迭代记录（发生了什么）

  • v0：先要「行业图谱 + 公司分类」，确认 9 类结构，避免范围漂移。
  • v1：按岗位产出 SOP，发现「奢侈品门店」与「设计师品牌电商」动作差异大 → 引入公司类型修正项。
  • v2：把 SOP 抽成「角色数据对象」，让生成器能组合 → 形成 roleSOP × typeModifier 模型。
  • v3：补齐 skill map（能力模型量化），让 SOP 不止「做什么」还知道「靠什么能力做」。
  • v4：统一视觉为「香槟金 × 深色编辑风」，提升可信度与可读性。

③ 如何扩展成 WorkBuddy Skill

把本页的 SOP 数据抽成 SKILL.md + 一个生成器脚本，即可封装为可被反复调用的 Skill：

mkdir -p ~/.codebuddy/skills/sh-fashion-sop cat > ~/.codebuddy/skills/sh-fashion-sop/SKILL.md <<'EOF' name: sh-fashion-sop description: 为上海时尚行业各类型公司/岗位生成员工SOP与技能图谱 triggers: [SOP, 员工手册, 入职, 时尚公司, 岗位流程] EOF # 把本文 roleSOP / typeModifier 数据写入 data.json， # 再加一个 run.sh 调用生成器即可。
💡 真正的 vibe coding 不是「一次生成就完事」，而是 描述 → 生成 → 校验 → 抽象成可复用资产（Skill） 的循环。这套 SOP 库你已经可以直接当作团队新人 onboarding 模板使用。
